🚀 Экспресс-диагностика

Когда ученик говорит «У меня не работает», задайте эти 3 вопроса:

  1. Текст ошибки: «Что именно написано в консоли/терминале?» (Читай последнюю строку!)
  2. Окружение: «Ты сохранил файл перед запуском?», «Тот ли файл ты запустил?»
  3. Изоляция: «Работал ли этот код 5 минут назад? Что ты изменил с тех пор?»

⌨️ Топ-5 горячих клавиш

Для VS Code / PyCharm:

  • Ctrl + / Закомментировать / раскомментировать строку
  • Alt + ↑ / ↓ Переместить строку кода вверх/вниз
  • Ctrl + D Выделить следующее вхождение (мультикурсор)
  • Ctrl + Shift + K Удалить всю строку
  • Ctrl + P Быстрый переход к файлу по имени
